Collect your keys

  • Do this once, before the install.
  • Each card is a list of numbered steps, in the order the website shows them.
  • Dark boxes: click Copy, then paste into the website. Type nothing yourself.
  • Yellow boxes: click or choose exactly that option on the website.
  • When a step says to copy a key, paste it into the box at the bottom of the card.
  • Images are always on. They are not a choice.
  • Then click Save keys file.
  • This page has no network access. It cannot send what you type. Your browser enforces that.
  • Nothing is saved in the browser. If you close or refresh this tab, the boxes are empty.
  • The saved file is plain text. Save it only in your private keys folder. Never in OneDrive, Dropbox, Git or email.
