Collect your keys

  • Do this once, before the install.
  • Every card marked Required is needed. The bar at the bottom shows how many are left.
  • Each card is a list of numbered steps, in the order the website shows them.
  • Dark boxes: click Copy, then paste into the website. Type nothing yourself.
  • Yellow boxes: click or choose exactly that option on the website.
  • When a step says to copy a key, paste it into the box at the bottom of the card.
  • Images are always on. They are not a choice.
  • Then click Save keys file.
  • This page has no network access. It cannot send what you type. Your browser enforces that.
  • Nothing is saved in the browser. If you close or refresh this tab, the boxes are empty.
  • The saved file is plain text. Save it only in your private keys folder. Never in OneDrive, Dropbox, Git or email.

Already saved a keys file? Choose it here. This page fills every box from it, so you do not type anything again.

Save your keys file in the right folder

  • The file holds every key. It must go in your private keys folder. Not Downloads. Not OneDrive, Dropbox or Google Drive.
Your private keys folder. Click Copy.
  1. Only if this folder does not exist yet: open File Explorer. Click the address bar. Paste %USERPROFILE% and press Enter. Right-click empty space. Click New, then Folder. Name it insight-forge-keys. (On a Mac: use Finder, and make a folder named insight-forge-keys in your home folder.)
  2. Click the green button below. A Save window opens.
  3. At the top of the Save window, click the folder address bar. Paste the folder from the box above. Press Enter. The window now shows that folder. (On a Mac: press Command, Shift, G in the Save window. Paste the folder. Press Enter.)
  4. The file name must say KEYS-TO-FILL.txt. Click Save. If it asks to replace the old file, click Replace.
  5. This page then says Saved. Tell Claude: filled.
